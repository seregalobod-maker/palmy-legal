Політика конфіденційності

Дата набрання чинності: 3 вересня 2026 р.

1. Загальна інформація

Ця Політика конфіденційності описує, як внутрішній сервіс Palmy ("Сервіс", "ми") обробляє дані у зв'язку з використанням програмних інтеграцій, зокрема API рекламних платформ (Google Ads API). Сервіс є внутрішнім інструментом компанії для автоматизації продажу товарів через месенджери (Telegram, Viber, WhatsApp) і не є публічним веб-застосунком для сторонніх користувачів.

2. Які дані ми обробляємо

У межах інтеграції з Google Ads API Сервіс отримує та обробляє:

  • статистику ефективності рекламних кампаній (покази, кліки, витрати, конверсії);
  • ідентифікатори кампаній, груп оголошень та рекламного акаунта;
  • дані відвідувань за рекламними посиланнями (клік-атрибуція) для зіставлення рекламних кампаній із замовленнями клієнтів у нашій системі.

Ми не отримуємо та не обробляємо через Google Ads API персональні дані відвідувачів рекламних оголошень (імена, контакти, платіжні дані третіх осіб).

Окремо, у межах роботи чат-бота в месенджерах, Сервіс обробляє дані клієнтів компанії (ім'я, номер телефону, адреса доставки, історія замовлень) виключно для оформлення та виконання їхніх власних замовлень.

3. Мета обробки даних

  • внутрішня маркетингова аналітика ефективності рекламних кампаній;
  • оцінка окупності реклами (ROI) на рівні компанії;
  • оформлення, обробка та доставка замовлень клієнтів;
  • ведення бухгалтерського та управлінського обліку компанії.

4. Зберігання та захист даних

Дані зберігаються на захищених серверах і доступні лише авторизованим співробітникам компанії, яким це необхідно для виконання службових обов'язків. Доступ до облікових записів Google Ads, підключених до Сервісу, захищений протоколом OAuth 2.0; ми не зберігаємо паролі від облікових записів Google.

5. Передача даних третім особам

Ми не продаємо та не передаємо дані, отримані через Google Ads API, третім особам, окрім випадків, прямо передбачених законодавством України, або якщо це необхідно для роботи технічних постачальників (хостинг, обробка платежів), пов'язаних договірними зобов'язаннями щодо конфіденційності.

6. Термін зберігання

Дані рекламної статистики зберігаються протягом строку, необхідного для аналітики та звітності компанії, але не довше, ніж це передбачено умовами використання Google Ads API та застосовним законодавством.

7. Права користувачів

Клієнти компанії, дані яких обробляються в межах виконання замовлень, мають право звернутися із запитом на перегляд, виправлення або видалення своїх персональних даних, надіславши запит на електронну адресу, вказану нижче.
